# Security policy

This is an educational local simulation, not a production authorization system.
Only the current `main` branch is maintained. There is no security SLA.

Please report potentially exploitable vulnerabilities privately to
fernando@moretes.com with the version, minimal synthetic reproduction,
expected/actual behavior and impact. Do not publish secrets or real findings.
Public issues are appropriate for ordinary bugs and documented lab limitations.
We will coordinate disclosure after assessing the report; no bounty is offered.

Em português: relate vulnerabilidades em privado para fernando@moretes.com,
usando apenas dados sintéticos. Não exponha credenciais ou dados de clientes.
